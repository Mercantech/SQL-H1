# Adgang til GameHubs data

Knyt hver kontrol til en trussel og et observerbart udfald.

| Kontrol | Efterprøv i undervisningslabben |
| ---|--- |
| Parametre | O'Neil er én værdi, og søgningen returnerer den rigtige profil. |
| Mindste rettighed | En læser kan hente leaderboardet og får afvist læsning af privat e-mail. |
| Brugeridentitet | API'et validerer token og kontrollerer adgang til den konkrete ressource. |
| Lager og backup | En autoriseret restore af krypterede data kræver også den rette nøgle. |

## Prøv opslaget

En forespørgsel udført af ejeren kan ikke alene bevise, hvad læserollen kan. Notér den faktiske rolle, den krævede handling og udfaldet.
