# Drift og databaseserver

Modul-skal til **Serverteknologi – Databaseserver** på H1:

- RDBMS-arkitektur og metadata (`pg_catalog`)
- Backup / restore (`pg_dump`, restore)
- Indeks, `EXPLAIN` og enkel performance
- Data ind og ud (`COPY`, dump)
- Oprette/slette database i den kontekst I bruger (Docker / sandbox)

I undervisningen kobles det til **Docker Compose** (Postgres-service, volumes, connection) i H1-pensum.
