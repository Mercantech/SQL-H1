# Raymonds reaktioner

De 48 WebP-filer er genbrugt uændret fra LUP-karakterbiblioteket:

`Mercantec.tech/web/wwwroot/images/characters/raymond/reactions/`

Ingen billeder er tegnet, genereret eller redigeret ved importen. De eksisterende
motiver bevarer Raymonds blå elefantidentitet, brune øjne og bronzebriller.
LUP-bibliotekets README og promptfiler dokumenterer de oprindelige illustrationer.

Det danske katalog findes i `web/src/lib/raymondReactions.ts`. Det indeholder
navn, beskrivelse, kategori og lokal URL til hvert motiv. Standardreaktionerne
skelner mellem vellykket SQL-kørsel, bestået opgave og fejl; de visuelle udtryk
erstatter ikke den konkrete status eller forklaring i tekst.

Billederne leveres lokalt med siden og kræver ingen forbindelse til LUP under brug.
